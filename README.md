# DS1 Examen 2026

## Beschrijving
Dit project bevat de uitwerking van de DS1 examenopdracht.
De analyse gebeurt op basis van geboortedata en onderzoekt onder andere:
- Seizoensinvloeden
- Weekdag-effecten
- Unisex namen
- Relatie tussen aantal geboortes en aantal unieke namen

## Structuur
- `data/`: dataset
- `notebooks/`: Jupyter notebook met uitwerking
- `environment.yml`: reproduceerbare omgeving

## Installatie

```bash
conda env create -f environment.yml
conda activate ds1_exam
jupyter notebook
